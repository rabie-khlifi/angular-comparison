Interactive Angular learning project

Learn Angular concepts by comparing them

Angular Concepts Lab is an open-source collection of focused, interactive lessons. Each page places two related ideas side by side so you can see how they behave, when they differ, and when to use each one.

About the lab

Small examples, visible differences

The project covers components, reactivity, forms, routing, HTTP, testing, accessibility, rendering, and performance. Use the lessons in order as a learning path, or open only the comparison you need. Some lessons are best understood by inspecting their component templates, TypeScript, and CSS alongside the live example, so follow the GitHub link whenever you want to see how a concept is implemented.
