Concern HttpClient httpResource
Result Cold Observable Resource with state signals
Starts On subscription Eagerly from reactive request
Changing request Build/switch Observable pipeline Change a tracked signal
Best use Reads, mutations, event streams Reactive HTTP reads
Use HttpClient for mutations. POST, PUT, PATCH, and DELETE are imperative actions. Use httpResource primarily for GET-like reactive reads.
