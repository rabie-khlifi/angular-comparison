Old and modern optimization tools

  • Then: ChangeDetectionStrategy.OnPush, pure pipes, memoized selectors, lazy modules, and *ngFor trackBy.
  • Now: signals precisely mark consumers, computed() memoizes derivations, @for track preserves DOM identity, standalone routes lazy-load, and @defer splits optional UI.
  • OnPush remains useful; signals complement it rather than replace it.

Measure before optimizing. Use Angular DevTools profiler, browser Performance/Network panels, bundle budgets, source maps in appropriate environments, and production error telemetry. Watch long tasks, duplicate requests, layout shifts, memory growth, and oversized lazy chunks.

Important: the counters are teaching instrumentation, not a benchmark. Development mode performs extra checks. Profile an optimized production build on realistic hardware and data before making architecture decisions.
