Lesson 1

Standalone components vs NgModules

Both cards behave the same. The difference is how Angular discovers dependencies and how other code imports them.

What actually changes?

Question Standalone NgModule style
Who owns the component? The component is self-contained. Exactly one NgModule declares it.
Where are template dependencies listed? In the component's imports. In the declaring NgModule's imports.
How is it shared? Import the component class directly. Export it, then import its module.
Preferred for new code? Yes. Mainly existing code and module-based libraries.
Remember: standalone does not mean isolated, and NgModule does not change component behavior. They are dependency-organization models that can coexist.
