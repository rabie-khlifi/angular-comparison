Where NgRx fits

RxJS service: lightweight and flexible, but teams must invent conventions for actions, immutable updates, selectors, and debugging.

Signal store-style service: ideal for local or moderately shared synchronous state. Private writable signals plus public readonly/computed signals create a small predictable API.

NgRx Store: adds formal actions, reducers, selectors, effects, and excellent tooling for large cross-feature workflows. NgRx SignalStore offers structured signal-based stores. Neither NgRx package is installed here, so this lesson explains them honestly instead of presenting fake imports.

Start with the smallest design that meets actual coordination and debugging needs. Store libraries do not replace server state, HTTP caching policy, or good feature boundaries.
