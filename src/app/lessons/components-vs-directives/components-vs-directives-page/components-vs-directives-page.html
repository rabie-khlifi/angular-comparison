The same concepts before signals

Signals are only managing state in these examples. They do not determine whether a class is a component or directive. Older Angular code normally stored the same state in plain fields: 

isOnline = true;
isHighlighted = false;

toggleStatus() {
  this.isOnline = !this.isOnline;
}

Older directives also commonly used @HostBinding() and @HostListener(). Those decorators remain supported, but Angular now recommends the host metadata object used by InteractiveHighlight. Both styles add behavior to the existing host and neither gives a directive its own template.

Mental model: every component is a specialized directive with a template, but most directives are not components.
