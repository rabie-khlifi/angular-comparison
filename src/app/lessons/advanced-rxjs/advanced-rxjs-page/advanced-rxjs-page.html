Why each pipeline operator is here

  1. debounceTime(350) waits until typing pauses.
  2. distinctUntilChanged() skips consecutive duplicate terms.
  3. switchMap() cancels stale searches and keeps only the newest result.
  4. catchError() converts failure into a value so the UI stream stays alive.
  5. shareReplay(1) shares the latest result between multiple consumers.

Choose the correct flattening operator

switchMap: cancel old work. Best for searches and route-driven reads.

concatMap: queue work in order. Best when every save must complete sequentially.

mergeMap: run concurrently. Best for independent work when order is irrelevant.

exhaustMap: ignore new events while busy. Best for preventing double submits.

Signals do not replace RxJS operators. Use RxJS for asynchronous event streams, cancellation, concurrency, and composition. Use signals for synchronous UI state. AsyncPipe remains excellent; toSignal() is useful when the rest of a component uses signals.
