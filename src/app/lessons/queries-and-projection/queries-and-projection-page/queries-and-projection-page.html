Lesson 16

View queries, content projection, and template containers

Queries locate existing view objects; projection and template containers decide where and when markup renders.

@ViewChild vs viewChild()

A view query searches markup owned by the component's own template.

@ContentChild vs contentChild()

A content query searches markup supplied by the parent and placed using ng-content.
